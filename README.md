# 📊 場合の数 計算シミュレーター (Combinatorics Calculator in Rust)

Rust と `egui` (eframe) を使用して作られた、場合の数（階乗、順列、組合せ）をリアルタイムに計算・シミュレーションするデスクトップGUIアプリケーションです。

スライダーを動かすだけで、数式の理論値を瞬時に計算して表示します。

## 🚀 主な機能

- **リアルタイム計算**: スライダーで $n$（全体の要素数）と $r$（選択する数）を変更すると、即座に結果がアップデートされます。
- **安全設計**: 常に $r \le n$ の関係が維持されるよう、GUI側で動的に制限がかかります。
- **オーバーフロー対策**: 内部計算に `u128` 型を採用し、大きな数値（$30!$ 程度まで）の計算に対応しています。
- **日本語対応**: OS標準のフォントを自動で読み込み、文字化けのない綺麗な日本語表示を行います。
- **警告表示**: $n$ の値が大きくなり、桁数が膨大になった際には画面に警告を表示します。

## 🛠️ 動作環境 / 依存関係

- **言語**: Rust (Edition 2021 以降を推奨)
- **主要クレート**: `eframe = "0.26"` (egui)
- **対応OS**: Windows, macOS, Linux (各OSの標準日本語フォントを自動参照します)
